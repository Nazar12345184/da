РЕКЛАМНІ БАНЕРИ / ADVERTISEMENT IMAGES
=======================================

Покладіть сюди файли реклами з такими іменами:

  advertisement1.png  — Широкий банер (728×90 px) — "leaderboard"
  advertisement2.png  — Прямокутний банер (300×90 px) — "rectangle"
  advertisement3.png  — (за потреби) додатковий банер

Підтримувані формати: .png, .jpg, .jpeg, .webp, .gif

Розміри:
  Широкий (leaderboard): 728 x 90 px
  Прямокутний (rect):    300 x 90 px
  Повна ширина (strip):  1100 x 80 px

Після того як покладете файли — банери автоматично з'являться на сторінках.
